# CapitalBridge Intelligence 사용자 가이드

## 1. 이 프로그램은 무엇인가요?

CapitalBridge Intelligence는 인테리어 사업자를 위한 AI 업무 도구입니다.

고객 상담 내용을 정리하고, 견적 초안과 제안서 문안, SNS 홍보 글을 빠르게 만들 수 있습니다. 협력업체 정보도 함께 관리할 수 있어 상담부터 현장 운영까지 한 화면에서 처리하는 데 목적이 있습니다.

쉽게 말하면, 인테리어 회사의 고객 장부, 문서 초안 작성 도우미, 홍보 문구 작성 도구, 협력업체 관리표를 하나로 합친 프로그램입니다.

## 2. 누가 사용하면 좋은가요?

- 인테리어 업체 대표
- 리모델링 상담 담당자
- 고객 견적서를 자주 작성하는 실무자
- 고객 제안서 작성에 시간이 많이 걸리는 사람
- 블로그, 인스타그램, 네이버 플레이스 홍보 문구가 필요한 사람
- 목공, 전기, 설비, 도배, 필름, 타일 등 협력업체 정보를 체계적으로 관리하려는 사람

## 3. 접속 방법

운영 사이트:

https://jh-capitalbridge-intelligence.vercel.app

PC, 태블릿, 모바일 브라우저에서 사용할 수 있습니다.

## 4. 모바일 앱처럼 설치하는 방법

### Android

1. Chrome으로 운영 사이트에 접속합니다.
2. 오른쪽 위 메뉴를 누릅니다.
3. `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.
4. 홈 화면에 생긴 아이콘으로 실행합니다.

### iPhone

1. Safari로 운영 사이트에 접속합니다.
2. 하단 공유 버튼을 누릅니다.
3. `홈 화면에 추가`를 선택합니다.
4. 홈 화면에 생긴 아이콘으로 실행합니다.

## 5. 기본 사용 순서

1. `고객 관리`에서 고객을 등록합니다.
2. 고객의 상담 내용, 공간 유형, 예산, 희망 스타일, 요청사항을 정리합니다.
3. `견적 자동화`에서 AI 견적 초안을 생성합니다.
4. `제안서 생성`에서 고객에게 전달할 제안 문안을 생성합니다.
5. `SNS 콘텐츠`에서 홍보용 게시글 초안을 생성합니다.
6. `협력업체`에서 시공팀과 자재업체 정보를 관리합니다.
7. `대시보드`에서 전체 업무 현황을 확인합니다.

## 6. 메뉴별 사용법

### 대시보드

전체 업무 현황을 확인하는 첫 화면입니다.

고객 수, 진행 중인 프로젝트, 생성된 견적 현황을 확인하고 주요 기능으로 바로 이동할 수 있습니다.

### 고객 관리

고객 정보를 등록하고 관리하는 메뉴입니다.

관리할 수 있는 정보 예시는 다음과 같습니다.

- 고객명
- 연락처
- 프로젝트 내용
- 상담 상태
- 진행 상태
- 메모

고객 상태를 상담, 진행 중, 완료 등으로 구분해 관리할 수 있습니다.

### 견적 자동화

AI가 견적 초안을 만들어주는 메뉴입니다.

입력 예시:

- 아파트 32평
- 주방 리모델링
- 예산 2,000만 원
- 모던 스타일
- 수납공간 확대
- 조명 교체 포함

AI는 입력 내용을 바탕으로 공사 범위와 견적 방향을 정리합니다.

주의: AI 견적은 초안입니다. 실제 계약 전에는 자재 단가, 인건비, 현장 조건, 공사 범위를 반드시 사람이 확인해야 합니다.

### 제안서 생성

고객에게 설명할 제안 문안을 만드는 메뉴입니다.

고객 취향, 공간 목적, 예산, 원하는 스타일을 입력하면 AI가 디자인 방향, 자재 추천, 공간 구성 아이디어를 문장으로 정리합니다.

활용 예:

- 상담 후 고객에게 보낼 제안 메시지
- 제안서 문서 초안
- 디자인 콘셉트 설명문
- 자재와 가구 방향성 정리

### SNS 콘텐츠

시공 사례나 홍보 글을 빠르게 작성하는 메뉴입니다.

입력 예시:

- 30평대 아파트 거실 시공
- 간접조명 적용
- 밝은 톤의 벽지 사용
- 맞춤 수납장 제작

AI는 입력 내용을 바탕으로 인스타그램, 블로그, 네이버 플레이스 등에 활용할 수 있는 홍보 문구 초안을 만듭니다.

### 협력업체

시공에 필요한 파트너 정보를 관리하는 메뉴입니다.

등록 대상 예시:

- 목공팀
- 전기팀
- 설비팀
- 도배 업체
- 필름 업체
- 타일 업체
- 자재 납품업체

업체명, 담당 공종, 연락처, 메모를 저장해두면 현장 운영 중 빠르게 확인할 수 있습니다.

## 7. 실제 업무 활용 예시

### 고객 상담 직후

1. `고객 관리`에 고객을 등록합니다.
2. 상담 내용을 메모합니다.
3. `견적 자동화`에서 견적 초안을 만듭니다.

### 고객에게 제안이 필요할 때

1. 고객의 취향, 예산, 공간 목적을 입력합니다.
2. `제안서 생성`에서 문안을 생성합니다.
3. 생성된 문안을 검토하고 고객에게 전달합니다.

### 홍보 글이 필요할 때

1. 완료된 시공 내용을 정리합니다.
2. `SNS 콘텐츠`에서 홍보 문구를 생성합니다.
3. 사진과 함께 SNS나 블로그에 게시합니다.

### 현장 운영 중

1. `협력업체`에서 공종별 업체 정보를 확인합니다.
2. 필요한 업체 연락처와 메모를 확인합니다.

## 8. 주의사항

- AI가 생성하는 내용은 최종본이 아니라 초안입니다.
- 실제 견적 금액, 자재 단가, 인건비, 공사 일정, 계약 조건은 반드시 사람이 검토해야 합니다.
- 고객에게 전달하기 전 문장과 숫자를 확인해야 합니다.
- API 키, 서비스 롤 키, 비밀번호 같은 비밀 정보는 GitHub나 화면에 공개하면 안 됩니다.

이 프로그램은 업무를 대신 확정하는 도구가 아니라, 반복적인 정리와 문서 초안 작성을 빠르게 도와주는 보조 도구입니다.
