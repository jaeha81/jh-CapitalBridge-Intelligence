# CapitalBridge Intelligence

CapitalBridge Intelligence는 인테리어 사업자가 고객 관리, AI 견적 초안, 제안서 문안, SNS 홍보 문구, 협력업체 관리를 한 곳에서 처리할 수 있는 업무 운영 프로그램입니다.

## 바로 사용하기

- 운영 사이트: https://jh-capitalbridge-intelligence.vercel.app
- 사용자 설명서: [docs/user-guide.md](docs/user-guide.md)

## 주요 기능

- 고객 등록 및 진행 상태 관리
- AI 견적 초안 생성
- 고객 제안서 문안 생성
- SNS/블로그 홍보 문구 생성
- 협력업체 DB 관리
- 모바일 반응형 화면
- 모바일 홈 화면 앱 설치 지원

## 모바일 설치

- Android Chrome: 사이트 접속 후 메뉴에서 `앱 설치` 또는 `홈 화면에 추가`
- iPhone Safari: 공유 버튼에서 `홈 화면에 추가`

AI 생성 결과는 초안입니다. 실제 견적, 계약 조건, 공사 일정, 자재 단가 등은 반드시 사람이 최종 검토해야 합니다.
